# Quiz App

**English** | [Türkçe](README.tr.md)

A quiz platform for testing your knowledge now and then:
- Difficulty by education level
- Software topics
- A daily question that is the same for everyone
- Questions generated on the fly from real data

Answers stay on the server, so you can't cheat by inspecting the browser.

> Work in progress. The plan below will become the full README when the project reaches v1.0.

## Features (plan)

**Questions**
- [ ] General subjects (Maths, Science, History, Geography, Literature and Art, General Knowledge) at 5 levels: Primary, Middle School, High School, University, Master's
- [ ] Specialist tracks: Software → JavaScript, Python, SQL, Git, HTML and CSS, Web Security, Algorithms, C# (Beginner / Intermediate / Advanced)
- [ ] Questions generated on the fly from templates, using real data from Wikidata (people, countries, books and films, elements); maths questions come from generators too
- [ ] Question types:
  - Multiple choice
  - Flag questions
  - Chronological ordering (drag and drop or keyboard)
  - "What does this code print?"
- [ ] After each answer the correct answer and a short explanation are shown

**Game**
- [ ] 10-question rounds with a timer and a speed bonus; jokers (50:50, +10 s)
- [ ] Daily question: the same question for everyone, with an emoji result to share
- [ ] Daily streak, statistics per subject and level, achievement badges
- [ ] "My mistakes" mode: wrongly answered questions come back until you get them right

**Security and infrastructure**
- [ ] Question generation, answer checking and scoring run in Vercel serverless functions; the browser can't see an answer in advance
- [ ] Round state is kept in an encrypted (AES-256-GCM), single-use token; rate limiting and server-side validation
- [ ] Turkish and English interface, dark and light theme matching my portfolio, keyboard and screen-reader support
- [ ] Logic in separate modules, tested with Node's built-in test runner

**Later**
- "Pick your own topic" rounds generated by AI
- Accounts for a streak that follows you across devices
- More specialist tracks
- Verifiable result links

## Tech Stack

- HTML, CSS, JavaScript (ES modules, no framework, no build step)
- Vercel serverless functions (Node.js), Upstash Redis
- `node --test` for unit tests
